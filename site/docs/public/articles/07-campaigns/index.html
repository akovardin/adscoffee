07 Рекламодатели и кампании

 

Рекламодатели

Рекламодатель — верхний уровень собственной рекламы. Это компания или человек, чьи объявления вы показываете. В админке раздел называется «Рекламодатели».

Для рекламодателя указываются Заголовок, Информация, ОРД Контракт, даты начала и окончания и статус. У рекламодателя настраиваются собственные таргетинг, бюджет, каппинг и расписание, которые наследуются его кампаниями, группами и креативами.

Структура собственной рекламы:

Рекламодатель → Кампания → Группа → Креатив

Заголовок рекламодателя в списке ведёт на кампании с фильтром по этому рекламодателю. Удалить рекламодателя нельзя — только архивировать (архивация каскадно архивирует кампании, группы и креативы).

Кампании

Кампания — это размещение рекламы через платформу. В админке раздел называется «Кампании».

Чтобы создать кампанию, укажите:

  • Заголовок.
  • Рекламодателя.
  • Бандл приложения (Bundle) — используется для таргетинга по приложениям.
  • Даты начала и завершения.
  • Активность (включена/выключена).

Ставка (CPM) задаётся не у кампании, а у группы и креатива: сервер берёт цену креатива, а если она нулевая — цену группы.

Заголовок кампании в списке ведёт на группы с фильтром по кампании. В списке кампаний есть фильтры по архиву, рекламодателю, активности и дате создания.

Удалить кампанию нельзя — только архивировать.

Таргетинг

Таргетинг определяет, где, когда и кому показывать рекламу. Он настраивается у рекламодателя, кампании, группы и креатива, а сервер объединяет значения всех уровней. В админке доступны блоки:

  • Бандлы — идентификаторы приложений (com.example), include/exclude по OR.
  • Страны — коды стран (RU, US).
  • Регионы — коды регионов (MOW, SPE).
  • Города — коды городов (KUF, OMS).
  • IP — сети в формате CIDR (188.170.172.0/22).
  • Плейсменты — выбор плейсментов из выпадающего списка с поиском (мультивыбор); сохраняются числовые ID.

Таргетинг хранится как JSON на каждом уровне. Пример таргетинга по плейсментам:

{
  "placement": {
    "include_or": ["2", "4"],
    "exclude_or": ["3"]
  }
}

Поля include_or/exclude_or означают «показывать, если совпал хотя бы один» / «скрывать, если совпал хотя бы один». Правило placement сравнивает ID запрошенного плейсмента с этими списками.

Бюджеты, каппинг и расписания

Помимо таргетингов, у рекламодателей, кампаний, групп и креативов настраиваются:

  • Бюджет — лимиты по показам, кликам, деньгам и конверсиям (за день и всего, с опцией равномерного расходования).
  • Каппинг — ограничение частоты показов одному пользователю (количество за период).
  • Расписание (Timetable) — по каким дням и часам показывать рекламу.

Эти настройки проверяются рекламным сервером на этапе limits при выборе объявления.
