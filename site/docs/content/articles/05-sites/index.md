# 05 Сайты
<p>&nbsp;</p>

Настройку монетизации начинайте с добавления сайтов. Сайт — это ваш ресурс, на котором будет отображаться реклама: сайт, страница документации, репозиторий, десктопное или мобильное приложение. В админке сайты находятся в разделе **«Сайты»**.

Чтобы добавить сайт, укажите:

- **Заголовок** — название сайта.
- **Активность** — включён или выключен.

После добавления сайт появится в общем списке. Нажав на него, можно изменить данные. Удалить сайт нельзя — только архивировать (пункт меню строки «Архивировать»).

## Статус сайта

- **Включённый** сайт отдаёт рекламу по своим плейсментам.
- **Выключенный** сайт рекламу не отдаёт: запрос к любому его плейсменту завершается `200 OK` с пустым ответом. SDK и JS-виджет обрабатывают такой ответ как «рекламы нет» (noad) и ничего не показывают. Настройки сайта при этом сохраняются.

## Связанные плейсменты

У одного сайта может быть неограниченное количество [плейсментов](/docs/articles/06-placements/). Заголовок сайта в списке — это ссылка: она открывает список плейсментов с уже применённым фильтром по этому сайту.
