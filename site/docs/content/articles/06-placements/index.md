# 06 Плейсменты и юниты
<p>&nbsp;</p>

## Плейсменты

Плейсмент — это место на сайте, где отображается реклама. Это может быть элемент сайдбара, футер, место внутри статьи, README или любой другой элемент страницы или приложения. В админке плейсменты находятся в разделе **«Плейсменты»**. Они всегда привязаны к конкретному [сайту](/docs/articles/05-sites/), и у одного сайта может быть неограниченное количество плейсментов.

Чтобы создать плейсмент:

1. Укажите **Заголовок**.
2. Выберите **Сайт**.
3. Установите **Активность** (включён/выключен).

У каждого плейсмента есть числовой **ID** — он подставляется в URL рекламного сервера (`/native/<id>`, `/banner/<id>/...`, `/inapp/<id>`). Этот ID виден в списке плейсментов в колонке `ID`.

Удалить плейсмент нельзя — только архивировать. Выключенный плейсмент рекламу не отдаёт, но продолжает хранить настройки и статистику.

Заголовок плейсмента в списке — ссылка на список юнитов с фильтром по этому плейсменту. В списке плейсментов есть фильтры по архиву, активности и сайту.

Готовые примеры подключения — баннер, нативный JSON, JS-виджет и Android SDK — описаны в разделе [Интеграция рекламы](/docs/articles/09-integration/).

## Юниты (медиация)

Юнит — это предложение рекламной сети, привязанное к плейсменту. Через юниты один и тот же плейсмент может заполняться несколькими источниками рекламы: собственными кампаниями и партнёрскими сетями. Для юнита указываются:

- **Заголовок**.
- **Плейсмент**, который он заполняет.
- **Сеть**, из которой приходит реклама.
- **Ставка** (`Price`) — участвует во взвешенном выборе между кандидатами.
- **Формат** — `banner` или `interstitial`.
- **Данные** (`Data`) — произвольный конфиг, который передаётся в сеть (например, идентификатор блока Yandex).

Когда на плейсмент приходит запрос, этап `mediation` рекламного сервера сравнивает собственных кандидатов (креативы) и юниты сетей и по взвешенному алгоритму выбирает лучший оффер. Подробнее о сетях — в разделе [Источники рекламы](/docs/articles/11-sources/).

В списке юнитов есть фильтры по архиву, активности, формату, плейсменту и сети. Заголовок сети в списке [рекламных сетей](/docs/articles/11-sources/) ведёт на юниты с фильтром по этой сети.

## Группы

Группа — это промежуточный уровень между кампанией и креативами (**Рекламодатель → Кампания → Группа → Креатив**). Группа позволяет разбить кампанию на части и задать общие параметры (цену, расписание, таргетинг) для набора креативов.
