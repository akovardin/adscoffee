# 04 Пользователи
<p>&nbsp;</p>

Доступ в админ-панель защищён логином и паролем. Пользователи хранятся в вашей базе данных и создаются вами же.

## Создание пользователя

Управление пользователями выполняется командой `user` (алиас `u`) образа `platform-admin`. Команда создаёт пользователя с указанным логином, а если такой уже существует — обновляет ему пароль:

```sh
# в каталоге dist/

# пользователь по умолчанию admin / password
docker compose run --rm admin user -c=/configs/config.yaml

# свой логин и пароль
docker compose run --rm admin user -c=/configs/config.yaml -account=bob -password=S3cret
```

Для уже запущенного контейнера команду можно выполнить без создания нового:

```sh
docker compose exec admin /admin user -c=/configs/config.yaml -account=bob -password=S3cret
```

### Флаги

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--account`, `-a` | `admin` | Логин пользователя |
| `--password`, `-p` | `password` | Пароль пользователя |
| `--config`, `-c` | — | Путь к конфигу внутри контейнера (`/configs/config.yaml`) |

Если конфиг не указан, используется `admin/configs/config.yaml`.

> По умолчанию создаётся `admin` / `password` — обязательно смените пароль.

## Управление из админки

Новых пользователей также можно добавлять прямо в админке, в разделе **«Пользователи»**. Там же можно менять существующих пользователей и их пароли.

## Вход

Откройте админку по адресу `http://<ваш-хост>:8072` и войдите под созданным логином. При работе через HTTPS обязательно установите `CookieSecure=true` в `dist/.env` — иначе браузер не сохранит cookie и вход не сработает.
