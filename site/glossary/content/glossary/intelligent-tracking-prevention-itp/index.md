# Intelligent tracking prevention (ITP)
## Интеллектуальная защита от отслеживания
<p>&nbsp;</p>

Интеллектуальная защита от отслеживания (ITP) — это функция конфиденциальности в Webkit, движке с открытым исходным кодом, который используется в браузере Safari и других продуктах Apple. ITP была представлена в Safari 11 и iOS 11.  

### Как это работает:  
- **Блокировка отслеживания**: ITP ограничивает использование cookies первого уровня ([first-party cookies](/glossaries/glossary/first-party-cookie/)) для отслеживания пользователей.  
- **Очистка данных**: Cookies, которые используются для [ретаргетинга](/glossaries/glossary/retargeting/) и атрибуции, автоматически удаляются через 7 дней.  
- **Ограничение доступа**: Сторонние cookies блокируются по умолчанию.  

### Основные функции ITP:  
- **Блокировка cross-site tracking**: Предотвращение отслеживания пользователей на разных сайтах.  
- **Ограничение срока жизни cookies**: Cookies, используемые для отслеживания, удаляются через короткий период.  
- **Защита конфиденциальности**: Уменьшение количества данных, которые могут быть собраны о пользователях.  

### Пример:  
- Пользователь посещает сайт A, который устанавливает cookie для отслеживания.  
- Через 7 дней этот cookie автоматически удаляется, даже если пользователь продолжает посещать сайт.  

### Влияние на рекламную индустрию:  
- **Ретаргетинг**: Усложнение процесса показа рекламы пользователям, которые уже взаимодействовали с брендом.  
- **Атрибуция**: Затруднение отслеживания конверсий и определения эффективности каналов.  
- **Аналитика**: Снижение точности данных о поведении пользователей.  

### Преимущества для пользователей:  
- **Конфиденциальность**: Уменьшение количества данных, которые могут быть собраны о пользователях.  
- **Контроль**: Пользователи получают больше контроля над своими данными.  

ITP — это важный шаг в защите конфиденциальности пользователей, который оказывает значительное влияние на рекламную индустрию, заставляя компании искать новые способы работы с данными.
