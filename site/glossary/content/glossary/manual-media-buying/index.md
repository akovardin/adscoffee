# Manual media-buying
## Ручная закупка рекламы
<p>&nbsp;</p>

**Ручная закупка медиа (Manual Media-Buying)**  
Ручная закупка медиа — это процесс, при котором рекламодатель покупает рекламное пространство напрямую у [издателя](/glossaries/glossary/publisher/), без использования [AdTech-платформ](/glossaries/glossary/adtech-platform/) ([рекламных серверов](/glossaries/glossary/ad-server/), [DSP](/glossaries/glossary/demand-side-platform-dsp/), [SSP](/glossaries/glossary/supply-side-platform-ssp/)).  

### Как это работает:  
- Рекламодатель связывается с [издателем](/glossaries/glossary/programmatic/) через отдел продаж.  
- Стороны договариваются об условиях:  
   - Цена (например, фиксированная ставка CPM).  
   - Размещение (например, главная страница).  
   - Формат (например, баннер, видео).  
- Рекламное объявление размещается на сайте издателя.  

### Пример:  
- Рекламодатель договаривается с издателем о показе баннера на главной странице сайта за $10 CPM.  

### Преимущества ручной закупки медиа:  
- **Контроль**: Рекламодатель может точно выбрать место и время показа.  
- **Персонализация**: Возможность обсудить индивидуальные условия с издателем.  
- **Доверие**: Прямое взаимодействие с издателем может укрепить партнёрские отношения.  

### Недостатки:  
- **Трудоёмкость**: Требует значительных временных и человеческих ресурсов.  
- **Ограниченный масштаб**: Сложно управлять большим количеством сделок вручную.  
- **Отсутствие автоматизации**: Нет возможности использовать данные для оптимизации в реальном времени.  

### Противоположность: Программатик-закупка (Programmatic Media-Buying)  
- **Реальный пример**: Использование DSP для автоматической закупки инвентаря через аукционы RTB.  
- **Преимущества**: Автоматизация, масштабируемость, использование данных для оптимизации.  

### Современное применение:  
- Крупные издатели и рекламодатели всё ещё используют ручную закупку для премиальных сделок, но часто дополняют её программатик-платформами для автоматизации доставки и отчётности.  

Ручная закупка медиа — это традиционный метод, который остаётся актуальным для премиальных сделок, но постепенно уступает место программатик-закупке благодаря её эффективности и масштабируемости.
