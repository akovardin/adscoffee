# Frequency capping
## Ограничение частоты показов
<p>&nbsp;</p>

Ограничение частоты показов — это настройка, которая ограничивает количество показов одного и того же рекламного объявления одному пользователю за определённый период времени (например, 3 [показа](/glossaries/glossary/impression/) за 24 часа).  

### Как это работает:  
- Рекламодатель устанавливает ограничение на количество показов (например, не более 3 раз в день).  
- Когда пользователь видит рекламу, система отслеживает количество показов.  
- После достижения лимита реклама больше не показывается этому пользователю в течение установленного периода.  

### Пример:  
- Рекламодатель устанавливает ограничение: 3 показа за 24 часа.  
- Пользователь видит рекламу 3 раза в течение дня.  
- На четвёртый раз реклама не показывается, даже если пользователь продолжает посещать сайт.  

### Преимущества ограничения частоты показов:  
- **Эффективность бюджета**: Предотвращение перерасхода средств на повторные показы одному и тому же пользователю.  
- **Увеличение охвата**: Показ рекламы большему количеству уникальных пользователей.  
- **Улучшение пользовательского опыта**: Избежание раздражения пользователей из-за чрезмерного количества показов.  

### Когда использовать frequency capping:  
- Для кампаний с ограниченным бюджетом.  
- Для предотвращения «баннерной слепоты» (когда пользователи начинают игнорировать рекламу).  
- Для повышения эффективности кампаний с акцентом на охват.  

### Пример использования:  
- Рекламодатель запускает кампанию с ограничением: 5 показов за неделю.  
- Это позволяет охватить больше уникальных пользователей и избежать перегрузки рекламой.  

Ограничение частоты показов — это важный инструмент для оптимизации рекламных кампаний, который помогает рекламодателям эффективно использовать бюджет и улучшать взаимодействие с аудиторией.
