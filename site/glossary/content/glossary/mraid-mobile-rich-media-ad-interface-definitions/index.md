# MRAID (mobile rich media ad interface definitions)
<p>&nbsp;</p>

MRAID — это официальный API (интерфейс программирования приложений), используемый для отображения rich-media рекламы в мобильных приложениях.  

### Как это работает:  
- **Стандартизация**: MRAID предоставляет набор команд, которые работают с HTML5 и JavaScript (JS).  
- **Функции**:  
   - Расширение рекламы (например, раскрывающийся баннер).  
   - Изменение размера рекламы.  
   - Доступ к функциям мобильного устройства (например, вибрация, доступ к камере).  
- **Универсальность**: MRAID позволяет создавать единый rich-media креатив, который работает на разных операционных системах (iOS, Android) и в разных приложениях.  

### Преимущества MRAID:  
- **Упрощение разработки**: Нет необходимости создавать отдельные креативы для каждой платформы.  
- **Совместимость**: Rich-media реклама корректно отображается на всех устройствах и в приложениях.  
- **Интерактивность**: Возможность создания engaging-рекламы с использованием функций устройства.  

### Пример использования:  
- Рекламодатель создаёт интерактивный баннер с возможностью расширения.  
- С помощью MRAID баннер корректно работает как в iOS, так и в Android приложениях.  

### Основные функции MRAID:  
- **Расширение**: Реклама может раскрываться на весь экран.  
- **Изменение размера**: Адаптация рекламы под разные экраны.  
- **Доступ к устройству**: Использование функций устройства для повышения интерактивности.  

MRAID — это важный инструмент для создания rich-media рекламы, который упрощает разработку и обеспечивает совместимость на всех мобильных платформах.
