# Tag container
## Контейнер тегов
<p>&nbsp;</p>

Это специальный контейнер, который добавляется на сайт и содержит в себе различные теги, например, рекламные теги (ad tags) и теги аналитики (analytics tags).  

Контейнеры тегов обычно управляются с помощью системы управления тегами ([Tag Management System, TMS](/glossaries/glossary/tag-management-system-tms/)). Это позволяет легко добавлять, удалять или изменять теги без необходимости вмешательства в исходный код сайта.  

Представьте контейнер тегов как "коробку", в которой собраны все необходимые инструменты для отслеживания данных и показа рекламы. Вместо того чтобы размещать каждый тег отдельно, вы просто добавляете один контейнер, а TMS делает всю остальную работу.  

Это удобно, быстро и минимизирует риск ошибок. Контейнеры тегов — это как швейцарский нож для управления тегами на вашем сайте.
