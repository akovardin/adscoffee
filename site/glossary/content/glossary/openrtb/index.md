# OpenRTB
<p>&nbsp;</p>

OpenRTB — это открытый протокол, разработанный совместно с консорциумом [DSP](/glossaries/glossary/demand-side-platform-dsp/)/[SSP](/glossaries/glossary/supply-side-platform-ssp/) и принятый IAB (Internet Advertising Bureau) специально для [Real-time bidding (RTB)](/glossaries/glossary/real-time-bidding-rtb/).

### Основные функции OpenRTB:  
- **Стандартизация**: Установление единого языка для взаимодействия между покупателями и продавцами рекламы в режиме реального времени (RTB).  
- **Упрощение транзакций**: Позволяет [AdTech-платформам](/glossaries/glossary/adtech-platform/) (DSP, SSP, [рекламные биржи](/glossaries/glossary/ad-exchange/)) эффективно обмениваться данными.  
- **Масштабируемость**: Поддержка большого количества участников и транзакций.  

### Как это работает:  
- Пользователь заходит на сайт или в приложение.  
- SSP или рекламная биржа отправляет запрос на участие в аукционе (bid request) в DSP через протокол OpenRTB.  
- DSP анализирует запрос и делает ставку (bid response).  
- Победитель аукциона получает возможность показать своё объявление.  

### Преимущества OpenRTB:  
- **Прозрачность**: Чёткие правила и стандарты для всех участников.  
- **Эффективность**: Ускорение процесса закупки рекламы.  
- **Гибкость**: Поддержка различных форматов рекламы и моделей оплаты.  

### Пример использования:  
- Издатель использует SSP для продажи своего инвентаря через OpenRTB.  
- DSP получает запрос и делает ставку на основе данных о пользователе.  
- Победитель аукциона показывает своё объявление пользователю.  

### Кто использует OpenRTB:  
- **DSP**: Для покупки инвентаря в режиме реального времени.  
- **SSP**: Для продажи инвентаря издателей.  
- **Рекламные биржи**: Для организации аукционов.  

OpenRTB — это ключевой стандарт в программатик-рекламе, который обеспечивает эффективное взаимодействие между всеми участниками экосистемы.
