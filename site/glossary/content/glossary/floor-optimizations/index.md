# Floor optimizations
## Оптимизация минимальных ставок
<p>&nbsp;</p>

Оптимизация минимальных ставок — это различные тактики, которые издатели используют для максимизации доходов от рекламного инвентаря путём настройки механизмов аукционов с использованием мягких (soft) и жёстких (hard) минимальных ставок.  

### Что такое минимальные ставки:  
- **Жёсткая минимальная ставка ([Hard Floor](/glossaries/glossary/hard-floor-price/))**: Минимальная цена, ниже которой показ не будет продан.  
- **Мягкая минимальная ставка ([Soft Floor](/glossaries/glossary/soft-floor-price/))**: Минимальная цена, которая может быть пересмотрена(в зависимости от условий), если ставки ниже неё.  

### Тактики оптимизации:  
- **Динамические минимальные ставки**: Автоматическая корректировка минимальных ставок на основе спроса и других факторов.  
- **Сегментация инвентаря**: Установка разных минимальных ставок для разных типов инвентаря (например, премиальный vs. остаточный).  
- **Анализ данных**: Использование данных о прошлых аукционах для определения оптимальных минимальных ставок.  
- **Тестирование**: Постоянное тестирование и корректировка минимальных ставок для достижения максимального дохода.  

### Пример использования:  
- Издатель устанавливает жёсткую минимальную ставку $2 CPM для премиального инвентаря и мягкую минимальную ставку $1 CPM для остаточного инвентаря.  
- Если спрос низкий, мягкая минимальная ставка может быть снижена до $0,80 CPM, чтобы заполнить инвентарь.  

### Преимущества оптимизации минимальных ставок:  
- **Максимизация доходов**: Увеличение доходов за счёт оптимального ценообразования.  
- **Гибкость**: Возможность адаптироваться к изменениям спроса и рыночным условиям.  
- **Эффективность**: Улучшение заполняемости инвентаря без ущерба для доходов.  

Оптимизация минимальных ставок — это важный инструмент для издателей, который помогает максимизировать доходы от рекламного инвентаря и эффективно управлять аукционами.
