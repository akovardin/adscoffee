# Ad tag
## Рекламный тег
<p>&nbsp;</p>

Рекламный тег — это фрагмент кода, который вставляется в рекламный слот для отображения рекламного объявления.

Существуют различные типы рекламных тегов, включая:

- HTML или IMG теги — простые теги для отображения статичных изображений или HTML-контента.
- JavaScript теги — динамические теги, которые позволяют выполнять более сложные действия, такие как загрузка данных в реальном времени.
- Iframe теги — встраивают рекламу в отдельный фрейм на странице.
- SafeFrame теги — обеспечивают безопасное отображение рекламы, изолируя её от основного контента страницы.
- Mobile - код для размещения рекламы в приложениях.
- [VAST (Video Ad-Serving Template)](/glossaries/glossary/vast-video-ad-serving-template/) — теги для видеорекламы, которые стандартизируют передачу данных между видеоплеерами и рекламными серверами.
- [VPAID (Video Player Ad Interface Definition)](/glossaries/glossary/vpaid-video-player-ad-interface-definition/) — теги для интерактивной видеорекламы, позволяющие добавлять элементы взаимодействия, такие как кликабельные кнопки.

Цель рекламного тега — запрашивать определённую информацию и выполнять процессы при загрузке веб-страницы или мобильного приложения. Например, тег может связываться с рекламным сервером, чтобы определить, какое объявление показывать, и отслеживать показы или клики.

Кроме рекламных тегов, термин «тег» также используется для обозначения других типов тегов, например, тех, что применяются в веб-аналитике для сбора данных о поведении пользователей.

Рекламные теги являются важным инструментом для управления показом рекламы, её таргетинга и измерения эффективности.
