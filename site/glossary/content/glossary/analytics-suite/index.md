# Analytics suite
## Аналитический комплекс
<p>&nbsp;</p>

Аналитический комплекс — это набор интегрированных приложений для сбора, измерения, анализа, визуализации и обмена аналитическими данными.

Он разработан для того, чтобы пользователи любого уровня могли легко получать доступ к необходимым данным, эффективно сотрудничать, извлекать мгновенную пользу из информации и принимать более обоснованные бизнес-решения.

Пример: Piwik PRO Analytics Suite. Piwik PRO Analytics Suite включает следующие модули:

- Аналитика (Web, Product, App & Intranet) — сбор и анализ данных о поведении пользователей на сайтах, в приложениях и интранет-ресурсах.
- Управление тегами (Tag Management) — централизованное управление тегами для отслеживания и аналитики.
- Платформа данных о клиентах (Customer Data Platform) — создание единого профиля клиента на основе данных из различных источников.
- Управление согласиями (Consent Management) — управление согласиями пользователей на сбор и обработку их данных.
- Ретаргетинг на сайте (On-site Retargeting) — персонализация контента и рекламы для пользователей на основе их поведения.

Все продукты интегрированы в единую систему. Примеры взаимодействия между модулями:

- Менеджер тегов активирует тег аналитики.
- Менеджер согласий позволяет посетителю решить, какие категории тегов будут активированы.
- Данные из Аналитики передаются в профиль пользователя в Платформе данных о клиентах, где объединяются с другими данными, например, импортированными из CSV.

Такой комплексный подход позволяет бизнесу эффективно использовать данные для улучшения пользовательского опыта, оптимизации рекламных кампаний и повышения конверсий.

Аналитический комплекс — это мощный инструмент для компаний, которые хотят быть data-driven (ориентированными на данные) и принимать решения на основе точной и актуальной информации.
