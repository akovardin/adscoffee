# Reach
## Охват
<p>&nbsp;</p>

Охват — это количество людей, которые потенциально могут увидеть рекламу.  

### Как это работает:  
- Рекламодатель настраивает таргетинг кампании.  
- Платформа рассчитывает, сколько пользователей соответствует этим критериям.  
- Это число и есть охват.  

### Примеры:  
- **Широкий охват**: «Женщины, проживающие в США» — миллионы пользователей.  
- **Узкий охват**: «Женщины 20-25 лет, проживающие в Дублине, Ирландия, интересующиеся беговой обувью» — тысячи пользователей.  

### Преимущества широкого охвата:  
- **Узнаваемость бренда**: Возможность охватить большую аудиторию.  
- **Масштаб**: Подходит для кампаний с акцентом на узнаваемость.  

### Преимущества узкого охвата:  
- **Точность**: Реклама показывается только целевой аудитории.  
- **Эффективность**: Увеличение конверсий за счёт релевантности.  

### Пример использования:  
- Рекламодатель запускает кампанию с широким охватом для повышения узнаваемости бренда.  
- Другая кампания с узким охватом нацелена на конкретную аудиторию для увеличения продаж.  

### Как улучшить охват:  
- **Расширение таргетинга**: Добавление новых критериев (например, интересы, поведение).  
- **Использование разных каналов**: Показ рекламы на сайтах, в приложениях и социальных сетях.  

Охват — это важный показатель, который помогает рекламодателям планировать свои кампании и оценивать их потенциальную эффективность.
