# Piggybacking
## Пиггибэкинг
<p>&nbsp;</p>

Пиггибэкинг — это процесс, при котором активация одного [пикселя](/glossaries/glossary/pixel/) вызывает срабатывание пикселей других платформ.  

### Как это работает:  
- Пользователь посещает сайт, и срабатывает основной пиксель (например, для отслеживания конверсии).  
- Этот пиксель активирует пиксели других платформ, которые также начинают собирать данные.  
- Данные используются для синхронизации cookies и отслеживания конверсий.  

### Преимущества пиггибэкинга:  
- **Синхронизация данных**: Упрощение обмена данными между платформами.  
- **Отслеживание конверсий**: Возможность отслеживать действия пользователя на разных платформах.  
- **Эффективность**: Уменьшение количества пикселей на странице, что улучшает скорость загрузки.  

### Недостатки:  
- **Конфиденциальность**: Сбор данных через несколько платформ может вызывать вопросы о защите приватности.  
- **Сложность управления**: Требуется тщательная настройка и контроль.  

### Пример:  
- Рекламодатель использует пиггибэкинг для синхронизации данных между DSP и SSP.  
- Это позволяет показывать релевантную рекламу пользователям на разных платформах.  

Пиггибэкинг — это полезный инструмент для синхронизации данных и улучшения таргетинга, но его использование требует соблюдения норм конфиденциальности и защиты данных.
