# Hard-floor price
## Жёсткая минимальная ставка 
<p>&nbsp;</p>

**Также известна как**: hard price floor  

Жёсткая минимальная ставка — это минимальная цена, которую издатель готов принять за показы рекламы.  

### Как это работает:  
- [Издатель](/glossaries/glossary/publisher/) устанавливает минимальную цену (hard-floor price) для своего рекламного инвентаря.  
- Если ставка рекламодателя ниже этой цены, она автоматически отклоняется.  
- Показ не будет продан, если ни одна из ставок не превышает минимальную цену.  

### Пример:  
- Издатель устанавливает жёсткую минимальную ставку $2 CPM.  
- Рекламодатель A предлагает $1,80 CPM, рекламодатель B — $2,20 CPM.  
- Ставка рекламодателя A отклоняется, а показ продаётся рекламодателю B.  

### Преимущества жёсткой минимальной ставки:  
- **Защита доходов**: Издатель гарантирует, что инвентарь не будет продан по заниженной цене.  
- **Контроль качества**: Ограничение доступа к инвентарю для рекламодателей с низкими ставками.  
- **Прозрачность**: Чёткие правила для рекламодателей и платформ.  

### Недостатки:  
- **Риск недополучения доходов**: Если спрос низкий, инвентарь может остаться непроданным.  
- **Ограничение гибкости**: Жёсткая минимальная ставка не учитывает изменения рыночных условий.  

### Когда использовать жёсткую минимальную ставку:  
- Для премиального инвентаря, который имеет высокую ценность.  
- Для защиты бренда от низкокачественной рекламы.  

Жёсткая минимальная ставка — это важный инструмент для издателей, который помогает защитить доходы и контролировать качество рекламного инвентаря.
