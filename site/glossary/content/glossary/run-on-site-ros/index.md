# Run on site (ROS)
<p>&nbsp;</p>
  
Run on Site (ROS) — это метод таргетинга, при котором рекламная кампания запускается на определённых доменах или сайтах издателей в рамках [рекламной сети](/glossaries/glossary/ad-network/).  

### Как это работает:  
- Рекламодатель выбирает конкретные сайты или домены, на которых должна показываться реклама.  
- Рекламная платформа (например, DSP или Ad Network) настраивает кампанию для показа только на выбранных сайтах.  
- Рекламные объявления показываются пользователям только на этих сайтах.  

### Пример использования:  
- Рекламодатель хочет показывать рекламу на сайтах A, B и C.  
- В настройках кампании выбирается опция ROS и указываются эти сайты.  
- Реклама показывается только на сайтах A, B и C.  

### Преимущества ROS:  
- **Контроль**: Рекламодатель точно знает, где будет показываться реклама.  
- **Релевантность**: Возможность выбирать сайты, которые соответствуют целевой аудитории.  
- **Безопасность**: Исключение нежелательных сайтов из кампании.  

### Недостатки:  
- **Ограниченный охват**: Кампания показывается только на выбранных сайтах.  
- **Сложность масштабирования**: Требуется ручной выбор сайтов.  

### Пример:  
- Рекламодатель продвигает новый продукт и выбирает для показа рекламы только популярные новостные сайты.  
- Это позволяет охватить целевую аудиторию и избежать показов на нерелевантных сайтах.  

Run on Site — это полезный инструмент для рекламодателей, которые хотят контролировать размещение своей рекламы и показывать её только на определённых сайтах.
