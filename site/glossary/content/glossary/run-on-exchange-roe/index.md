# Run on exchange (ROE)
<p>&nbsp;</p>

Run on Exchange (ROE) — это рекламный инвентарь, доступный для покупки на [рекламной бирже](/glossaries/glossary/ad-exchange/).  

### Как это работает:  
- Издатели предоставляют свой рекламный инвентарь на биржу.  
- Рекламодатели (через DSP) могут покупать этот инвентарь через аукционы в реальном времени (RTB).  
- Рекламные объявления показываются пользователям на сайтах издателей.  

### Преимущества ROE:  
- **Широкий охват**: Доступ к большому количеству инвентаря на разных сайтах.  
- **Автоматизация**: Упрощение процесса закупки рекламы.  
- **Точность**: Возможность таргетировать аудиторию на основе данных.  

### Недостатки:  
- **Конкуренция**: Высокая конкуренция за премиальный инвентарь.  
- **Ограниченный контроль**: Рекламодатель не может выбрать конкретные сайты для показа.  

Run on Exchange — это эффективный способ для рекламодателей охватить большую аудиторию и управлять своими кампаниями через программатик-платформы.
