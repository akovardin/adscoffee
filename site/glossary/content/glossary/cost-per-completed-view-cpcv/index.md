# Cost per completed view (CPCV)
## Стоимость за завершённый просмотр (CPCV)
<p>&nbsp;</p>

CPCV (Cost per Completed View) — это модель оплаты, при которой рекламодатель платит только в том случае, если пользователь досмотрел видео или анимацию до конца.

### Как это работает:
- Рекламодатель запускает видеорекламу или анимацию.
- Оплата происходит только за те показы, где пользователь просмотрел ролик полностью.
- Если пользователь прерывает просмотр, оплата не взимается.

### Пример:
- Рекламодатель платит $10 за каждые 1000 завершённых просмотров.
- Если 500 пользователей досмотрели ролик до конца, а 500 — нет, рекламодатель заплатит только за 500 завершённых просмотров.

### Преимущества CPCV:
- Эффективность бюджета: Оплата только за реально просмотренный контент.
- Повышение качества взаимодействия: Рекламодатель заинтересован в создании увлекательного контента.

### Проблемы CPM и CPCV
Одной из ключевых проблем моделей CPM и CPCV является обеспечение того, что рекламу просмотрели реальные пользователи, а не боты. Для этого используются технологии проверки просматриваемых показов (viewable impressions), которые учитывают:
- Видимость рекламы на экране.
- Время просмотра.
- Уникальность пользователя.

### Когда использовать CPCV:
- Для видеорекламы, где важно, чтобы пользователь досмотрел ролик до конца.
- Для кампаний с акцентом на вовлечённость и взаимодействие.

CPCV — это эффективная модель для рекламодателей, которые хотят платить только за реальное внимание аудитории.
