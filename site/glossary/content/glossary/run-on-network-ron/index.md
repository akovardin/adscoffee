# Run on network (RON)
<p>&nbsp;</p>

Run on Network (RON) — это метод таргетинга, при котором рекламная кампания запускается на всех сайтах в рамках рекламной сети.  

### Как это работает:  
- Рекламодатель настраивает кампанию с опцией RON.  
- Рекламная платформа (например, DSP или Ad Network) показывает объявления на всех доступных сайтах в сети.  
- Реклама показывается пользователям на любом сайте, который входит в сеть.  

### Пример использования:  
- Рекламодатель запускает кампанию с опцией RON.  
- Рекламная сеть включает 1000 сайтов.  
- Реклама показывается на всех 1000 сайтах.  

### Преимущества RON:  
- **Широкий охват**: Реклама показывается на большом количестве сайтов.  
- **Простота**: Не требуется ручной выбор сайтов.  
- **Эффективность**: Возможность охватить разнообразную аудиторию.  

### Недостатки:  
- **Отсутствие контроля**: Рекламодатель не может выбрать конкретные сайты для показа.  
- **Риск нерелевантных показов**: Реклама может показываться на сайтах, которые не соответствуют целевой аудитории.  

### Пример:  
- Рекламодатель хочет повысить узнаваемость бренда и выбирает RON для максимального охвата.  
- Реклама показывается на всех сайтах в сети, что увеличивает видимость бренда.  

Run on Network — это удобный инструмент для рекламодателей, которые хотят максимально охватить аудиторию и не имеют строгих требований к выбору сайтов.
