# Universal ID
## Универсальный ID
<p>&nbsp;</p>

Это уникальный идентификатор пользователя, который позволяет AdTech-компаниям распознавать [пользователей](/glossaries/glossary/user/) на разных сайтах и устройствах.  

Универсальные ID создаются на основе данных, хранящихся в куках (обычно это [first-party cookies](/glossaries/glossary/first-party-cookie/)), а также идентификаторов устройств, таких как смартфоны, планшеты и другие гаджеты.  

Некоторые универсальные ID работают в рамках одной среды, например, только в веб-браузерах. Другие же стремятся идентифицировать пользователей в различных приложениях и девайсах, то есть и в браузерах, и на мобильных устройствах. Для этого используются так называемые "графы устройств" (device graphs), которые связывают ID, созданные в браузерах, с ID, сгенерированными на других устройствах, например, мобильными ID в смартфонах.  

Универсальный ID — это как "паспорт" пользователя в цифровом мире. Он помогает рекламодателям показывать релевантную рекламу, а платформам — точнее измерять эффективность кампаний. В эпоху, когда сторонние куки постепенно уходят в прошлое, универсальные ID становятся всё более важным инструментом для кросс-платформенного таргетинга и аналитики.
