# Contextual data
## Контекстный таргетинг
<p>&nbsp;</p>

Контекстные данные — это информация о содержании веб-страницы, которая используется для показа релевантной рекламы.

### Основные элементы контекстных данных:
- **URL**: Адрес страницы, который может указывать на её тематику.
- **Ключевые слова**: Слова и фразы, которые часто встречаются на странице и отражают её содержание.
- **Категории**: Тематические разделы, к которым относится страница (например, «спорт», «технологии», «путешествия»).
- **Теги**: Метки, которые описывают контент страницы.

### Как это работает:
- Рекламная система анализирует контекстные данные страницы.
- На основе этих данных подбираются релевантные объявления.
- Реклама показывается пользователю, даже если о нём нет дополнительной информации.

### Пример:
- Пользователь читает статью о здоровом питании.
- На странице встречаются ключевые слова: «диета», «витамины», «правильное питание».
- Рекламная система показывает объявления о витаминных добавках или фитнес-программах.

### Преимущества использования контекстных данных:
- **Релевантность**: Реклама соответствует содержанию страницы и интересам пользователя в данный момент.
- **Конфиденциальность**: Не требует сбора данных о пользователе, что делает его более приватным.
- **Универсальность**: Подходит для сайтов с разнообразным контентом.

### Применение:
- **Контекстный таргетинг**: Показ рекламы на основе содержания страницы.
- **Поисковая реклама**: Подбор объявлений на основе поисковых запросов.
- **Нативная реклама**: Интеграция рекламы в контент сайта.

Контекстные данные — это важный инструмент для повышения релевантности рекламы и улучшения пользовательского опыта.
