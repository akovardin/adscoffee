# Application programming interface (API)
## Интерфейс программного взаимодействия
<p>&nbsp;</p> 

API (Application Programming Interface) — это набор инструкций, который позволяет получать доступ к определённым функциям и данным других систем, таких как программное обеспечение, приложения или инструменты.

В контексте рекламных технологий([AdTech](/glossaries/glossary/adtech/)) API играет ключевую роль в интеграции различных платформ. С его помощью можно:

- Соединять одну [AdTech-платформу](/glossaries/glossary/adtech-platform/) с другой для обмена данными и функционалом.
Извлекать данные из одной системы и отображать их в пользовательском интерфейсе.
- Создавать новые приложения или улучшать существующие, используя возможности других систем.

Например, API может позволить рекламной платформе автоматически получать данные о кликах и конверсиях из системы аналитики, чтобы оптимизировать кампании в реальном времени. Это делает API незаменимым инструментом для автоматизации, масштабирования и повышения эффективности рекламных процессов.
